# 🌱 LeafNet

AI-powered plant disease diagnosis platform that helps identify
plant diseases from leaf images and provides actionable treatment
and prevention recommendations.

## 🚀 Features

- 📸 Plant leaf image upload
- 🤖 AI-powered disease diagnosis
- 📊 Confidence score
- 🔍 Differential diagnosis
- 💊 Treatment recommendations
- 🛡️ Prevention guidance
- 📚 Research-based sources
- 📱 Responsive interface

## 🛠️ Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- AI API
- MongoDB / InsForge
- React
- Express.js
- Node.js
